# UK Orbit Guard

A UK Parliament hackathon prototype that turns public orbital data and a synthetic close-approach scenario into questions a committee could scrutinise.

**Status:** Hackathon prototype (September 2026). Educational, not operational, and no official endorsement is claimed.

- Shows 2,661 public CelesTrak debris records on a 3D globe next to a synthetic encounter around a fictional satellite.
- Trains a tiny 65-weight policy in a network-blocked Daytona sandbox, and the host re-simulates every checkpoint.
- There is no performance result. The reinforcement learning is a teaching toy, and the 8× lead-time figure is constructed, not measured.
